This source adds a private normal-return consumer of the actual Native phase
actor. It accepts NativePhaseBinding, never a public Session/handle/status/receipt
ID or capability. Availability remains refused: the actual Native producer and
Runtime pre-Core retention are still being connected.

Planning uses the same original marker/current complete Workflow and Unit. A
second query-only snapshot rechecks that sealed currency before reading the
complete latest own Session (4MiB ceiling), actual allocated registered owner
(32KiB ceiling) and complete protected scoped negative identity history. These
reads therefore describe one coherent current state. Returned PID, initial native
UUID and record version can legitimately have advanced; returned native UUID,
when present, and immutable alias/provider/role/path/model/effort/start identity
must remain exact. A later change to the latest snapshot requires replanning,
never replacement of original pins or replay of Native input.

Negative observation takes both scoped record IDs and scoped projection IDs,
each stopping at4097 before union, then refuses a4097th distinct identity.
Missing, malformed, foreign-scope or mismatched-version projections refuse.

port reads bounded metadata rather than4096 complete recovery bodies. A distinct
historical Session with the same provider/non-null UUID refuses, including Lost.
It creates no owner or positive Native eligibility from that observation.

Normal binding requires the actual still-live registered actor, same retained
launch/allocation, exact registered owner/session_units/invocation relation and
eligible latest Unit. A closed invocation or terminal Session cannot use that
normal proof. The successful saved-terminal late predicate is not implemented
by this increment, so terminal races remain held until its actual producer and

live-TX check in planning and the normal binder's Immediate. The selected actual

their own phase/pair/lifecycle checks. Their wiring and genuine controls remain

error; this method invokes no ordinary fail/release/refresh path.
